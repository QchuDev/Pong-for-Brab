# PONG for BRAB
This is an excuse to test Bevy and to give an example of a fun application of Brab. 

### Objective
Have an environment to train a Pong Agent with the following algorithms:
1- Neuroevolution
2- DQN
3- PPO

The designed system might be ugly on the beginning, while learning how Bevy works I'll then comprehend how to design it under its shadow.
